A fix release of Downrush, the Deluge synth engine for standalone Akai MPCs and the Force. Nothing about parameters or saved projects changes: projects saved with 0.1.0 load as before.

## Fixed
- **A project could come up with another project's sounds.** A track whose sound is carried in the project itself (as in a song converted from a Deluge, or any sound with variations) could, when a second such project was loaded in the same session, play the first project's sound. Restarting the MPC between projects avoided it.
- **Revert on such a sound went to a library preset.** It now goes back to the sound the project carries, with all its variations.

## What you need
- A standalone MPC or a Force on MPC OS 3.10.1 or later, with Preferences > Enhancements (Beta) > Enable Enhancements and External Plugin Support switched on.
- Tested on one Akai Force (32-bit). A user reports 0.1.0 working on a 64-bit MPC Live III; we have not run the 64-bit build on a device ourselves.

## Install
Download `Downrush-0.1.1-mpc-sdk.zip`, unzip it, and copy the folder `Jamie Fenton - VST - Downrush` into a folder named `VST2 Plugins` at the top level of a drive the MPC can see, replacing the 0.1.0 folder. Copy your own presets and samples out of its `Content` folder first, and back afterwards. `INSTALL.txt` in the zip has the steps in full.
